# Student Registration System Using Python Flask

## Project Description
A beginner-friendly web application for registering students.

## Technologies Used
- Python
- Flask
- HTML
- CSS

## Features
- Student registration
- Input validation
- Registration result
- About page
- View registered students

## Installation
Install Python and Flask.

Run:

pip install -r requirements.txt

## How to Run
Open the terminal in the project folder.

Run:

python app.py

Open http://127.0.0.1:5000 in your browser.

## Routes
- / : Home page
- /about : About page
- /register : Registration form
- /students : Registered students

## Storage
Student information is stored temporarily in memory.
The records are lost when the application restarts.
